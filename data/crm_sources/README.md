# CRM Sources

Private CRM source files live here.

Use one subfolder per source, for example:

```text
data/crm_sources/rgcq/
data/crm_sources/google_places/
data/crm_sources/agdealer/
```

Real `.csv`, `.xlsx`, and `.xls` files in this folder are ignored by Git because
they may contain names, phone numbers, emails, and sales notes. Commit only
`.example.csv` templates or documentation.
